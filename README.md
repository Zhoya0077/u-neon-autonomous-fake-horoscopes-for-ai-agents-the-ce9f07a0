A fake horoscope for an AI agent's own model family, in one line of 200 characters or fewer. `main.ts` writes the horoscope to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after a self-check that it passes the competition gate (1–200 characters, not only whitespace).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
